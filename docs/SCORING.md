# Как формируется оценка

Десять направлений взяты из задания, которое ссылается на «Стартап как диплом». Это не подтверждение актуального положения конкретного конкурса. Веса ниже — продуктовая настройка, а не официальные обязательные веса.

| Критерий | Вес | Что ищем в питче и ответах |
| --- | ---: | --- |
| Реализуемость решения | 12% | Проблема, механизм решения, ограничения, прототип |
| Бизнес-модель | 14% | Покупатель, плательщик, способ оплаты, цена |
| Рынок и конкуренты | 12% | Сегмент, альтернативы, основание выбора продукта |
| Финансовая модель | 12% | Доход, расходы, маржа, согласованность допущений |
| ИС или регистрация | 5% | Права на продукт, лицензии либо регистрация |
| Первые продажи и спрос | 12% | Оплаты, пилоты, повторные покупки, результаты |
| Риски | 8% | Существенные риски и проверяемые меры |
| Горизонт планирования | 5% | Период прогноза, денежные потоки, сценарии |
| Уникальность | 8% | Значимое для клиента отличие с обоснованием |
| Инвестиционная привлекательность | 12% | Назначение инвестиций, этапы, потенциал роста |
| **Итого** | **100%** | |

## Шкала

| Балл | Основание |
| --- | --- |
| 0 | По критерию нет сведений |
| 1–2 | Очень слабое описание или существенные противоречия |
| 3–4 | Преимущественно предположения |
| 5–6 | Правдоподобная, но недостаточно подтверждённая модель |
| 7–8 | Конкретные, согласованные подтверждения в материалах |
| 9–10 | Исключительно сильное и подробно обоснованное описание |

Последние ступени описывают качество предоставленного обоснования. Они не означают независимую проверку покупателей или денег. Уверенный тон, длина ответа и модные слова не являются свидетельствами.

## Вычисление

```text
weighted_score = SUM(criterion.score × canonical_weight) / 100
```

Результат находится в диапазоне 0–10. Если каждый критерий получил 6, итог равен 6. Его вычисляет код. Сервер проверяет десять уникальных ID, диапазон баллов и полноту результата; веса берутся из единого справочника.

Каждая строка содержит `criterion_id`, `score`, `weight`, `explanation`, `evidence_quotes`, `missing_evidence`, `confidence`. Цитата принимается только как точная подстрока питча либо отдельного ответа. Без цитат сервер не принимает балл выше 2. Отсутствующие данные должны отражаться пустыми цитатами, объяснением и пробелами в данных. Цитата подтверждает происхождение слов, а не их истинность.

`confidence` — уверенность оценки по имеющемуся тексту, а не вероятность успеха бизнеса. Противоречия и отсутствующие сведения должны отражаться в пояснениях и баллах.

## Три рекомендации

Принимаются ровно три рекомендации. В каждой: название, проблема, точное действие, ожидаемый результат, срок, приоритет и связанные критерии. Предпочтительны изменения, выполнимые за 1–3 дня.

Например, таблица экономики одного заказа с ценой, переменными расходами и маржой — измеримый результат. «Улучшить финансовую модель» без результата и срока — недостаточно конкретно.

## Повторный раунд

Разница баллов показывает изменение качества представленных материалов. Это не доказательство роста выручки или привлекательности для реального инвестора. Test-балл не следует считать экспертным заключением.


## Что означает test-балл

Тестовый адаптер ищет ключевые слова по темам и наличие цифр. Его оценки ограничены 0–3, темы вопросов идут в фиксированном порядке, а цитата берётся из предыдущего ответа. Это намеренно несемантический алгоритм для проверки сценария. Он не оценивает достоверность, согласованность или инвестиционную привлекательность и не должен использоваться как экспертное заключение.
